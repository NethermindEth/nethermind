# Normal branch suffix: accepted conditional source-audited refinement

`BranchAcceptedIteration` is a separate operational extension. `BlockProcessorControl`
remains a syntax projection; its scope and theorem are not upgraded. Schema 2 / extractor
1.0.0 branch artifacts are independently accepted after the complete serialized gate and
executable review. The `source-admitted` marker is not a global verification claim. The
separate finite-branch completion and outer BlockchainProcessor publication are independently
accepted conditional caller-control refinements, not upgrades to this suffix's boundary.

The boundary begins after the first, normal, standard sequential, BAL-disabled `ProcessOne` return, with
an owned scope and nonempty branch already admitted. The generated runner evaluates the
upstream generated publication result and binds its returned block/receipt tuple directly.
No caller-chosen processed result or semantic output-equality premise is accepted. The
source-attached theorem invokes the upstream publication theorem and establishes a separately
defined branch observation relation. The computed publication model still consumes supplied
normal `ProcessBlock` inputs and its explicit adapter premises; this is not a complete
production `ProcessOne` or branch-entry execution proof.

The accepted gate passed 106/106 tests with no skips, 290 strict-schema negative controls,
deterministic regeneration, explicit Lake and direct Lean checks, seven compile-first semantic
mutations, and the complete 2,144-export standard-only axiom audit with negative/completeness
controls. The Release `Evm.slnx` build passed with zero warnings/errors; post-solution publication,
branch, Lean and diff checks passed. The root verifier invokes the complete nonrecursive
`Verify-Branch.ps1` gate without selecting the downstream draft targets.

## Represented order

1. Cancel/clear CTS, then write the tentative processed-array slot.
2. Check inclusion unless `NoValidation`; assign the signal to both blocks. False is not
   rejection, and skipped checking assigns true to both blocks.
3. Queue cache clearing and wait/clear the prewarm task.
4. Call `PreCommitBlock(suggestedBlock.Header)` and its exact
   `stateProvider.CommitTree(block.Number)` target. Increment the prefix only after normal return.
5. Invoke the optional read-write `BlockProcessed` event with the accepted block/receipts.
6. Reopen only at `!readOnly && index > 0 && index + 1 < total && index % 64 == 0`.
   Checkpoint reopening uses the suggested header; the next base uses the processed header.
7. Clear the prefetch handle, reset unconditionally, and optionally schedule transaction hashes.
8. On the terminal iteration, prepare return, unsubscribe, dispose the owned scope and invoke
   nested-finally completion before actual array return.

Results distinguish tentative slots from successful prefix count, both inclusion assignments,
scope lifecycle, commit/reset normal completion, task handles and returned-array identity.
Earlier populated slots, array bounds and C# integer domains are admitted explicitly.
Header, header-number and transaction-presence observations are typed read functions keyed by
the actual suggested or accepted processed block identity, not independent caller-filled headers.
Initial absent signals mean unobserved in this suffix, not that the block's old nullable fields
were null. Event evaluation does not assert that subscribers were present. A failing PreCommitBlock
can escape before its inner CommitTree call; the escape prefix does not invent that inner invocation.

## Trust and exclusions

The extractor, Roslyn, artifact checker and concrete runtime-selection adapter remain trusted.
External observations supply normal return, inclusion Boolean and reopened-scope identity;
they do not prove events, tracers, cancellation callbacks or state-operation implementations.
Normal hooks are assumed not to mutate other modeled identities. Mutable contents, aliasing,
interference, CLR behavior and full runtime source attachment remain adapter obligations.

CommitTree invocation/completion does not prove logical-state preservation, trie correctness,
durability, crash recovery or restart visibility. WorldState internal CFGs are audit anchors,
not implementation refinements. Explicit branch Reset is separate from reset during disposal.
Prewarm completion does not establish cache-clear-continuation completion; clearing prefetch
is not joining it; hash scheduling does not establish completed hashes.

An `escaped` result stops the model at a hook, with unknown final state and no returned array.
Its events form a prefix, not a claim that later C# exception unwinding did not run. The real
nested finally can still invoke completion after disposal throws. An already-assigned prefix
count is evidence of that local assignment, not a successful return. Rollback and complete
cleanup/exception-identity semantics are excluded.

BAL-enabled publication, BAL retry, parallel equivalence, validator rejection, unowned genesis, preloop acquisition,
branch selection, multi-block execution and outer BlockchainProcessor classification/head
publication remain separate. No full-branch-entry or finite-fold theorem is claimed.

## Reproducing the accepted gate

1. Gate ReceiptTerminal/normal-tail dependencies, then re-emit and gate accepted ProcessOne publication.
2. Build this extractor/tests warning-as-error; run source-only audits and the 106-test branch gate.
   Every source mutation first requires unmutated admission, separately compiles the mutation,
   then requires its exact anchor-specific admission diagnostic. The complete-token fallback
   runs after these anchor checks and cannot substitute for their diagnostics.
   Twenty-nine named callable controls cover local/delegate redirection, direct/aliased/inherited
   Conditional attributes, async/extern/iterator/partial declarations, and same-typed role,
   receiver and conversion changes. Unsupported callable shapes are rejected before CFG traversal.
   Publication mutations copy a fully accepted triplet to a disposable fixture and require the
   complete unmutated validator to pass before changing schema/version, duplicate fields,
   source/dependency closure, hashes, status or artifact presence. Draft baselines fail; no skips
   or synthesized accepted publication witnesses are permitted. Accepted-shape branch IR fixtures
   test only structural parsing/emission, never source attachment.
3. Extract branch artifacts twice to temporary directories and compare deterministic bytes.
   Each file is atomically replaced after a flushed same-directory temporary write; the manifest
   is published last. This is a fail-closed publication protocol, not a transactional directory
   swap or crash-durability theorem. Run `--branch-check` against the complete triplet.
4. Run explicit Branch and upstream vector Lake targets, then direct
   `lean -DwarningAsError=true` checks of generated, specification, refinement and vectors.
   Do not select unrelated downstream draft targets through the default Lake target list.
5. Run all seven compile-first semantic mutations and the complete frozen descendant-inclusive
   axiom census. The census includes the four Branch namespaces and all sixteen accepted
   ProcessOne/finalization/fold dependency roots: 2,144 theorem exports, partitioned into
   545 Branch exports and the unchanged 1,599 accepted upstream exports. The inventory SHA-256
   is `466024c46460b510b09519b1b860c73970c8b4b2585c5fa2a6bcd1664e4bd133`.
   Only `propext`, `Classical.choice`, and
   `Quot.sound` are admitted. Missing, unexpected, nested, forbidden and omitted-result controls
   must fail as expected. The final count and inventory digest are checked in the gate itself.
6. Run the complete `Verify-Branch.ps1`, then the Release warning-as-error `Evm.slnx` build with
   `SaveDiskSpace=true`, then upstream and branch freshness checks. Skip switches report partial
   checks only and cannot substitute for this complete gate.

Ten normal scenarios construct source admission and invoke the theorem: inclusion true/false/skipped,
read-only, interior/edge checkpoints, ordinary iteration, prewarm presence and empty transactions.
Additional vectors distinguish pre/post-commit escapes and refuse retry/parallel/unowned/rejected/
malformed-prefix inputs. C# mutations must remain compile-valid before admission rejection. Lean
semantic mutations must fail proofs after a passing baseline, not fail on imports or malformed syntax.
