# ProcessOne validated-publication generated artifact

This schema-2 / extractor-1.0.0 kernel is independently accepted for the conditional boundary below.
Its `source-admitted` marker alone records source admission and is not independent acceptance.
The separate `--publication-check` rederives the IR from live compiled source, validates strict
serialized records, and requires byte-exact Lean re-emission and the exact 52-entry
dependency closure. Default `--check` validates only finalization. `--publication-extract` writes
the three suffix artifacts through flushed same-directory atomic replacement with the manifest last.
Draft, stale, malformed, missing, duplicate, or unexpected evidence is rejected.

The theorem-free kernel consumes an adapter-supplied normal `ProcessBlock` result. Its bounded state records
the suggested/processed execution artifacts, receipts, validator normality/acceptance and proposed
GeneratedBlockAccessList observation, disposal, and ordered publication events. It distinguishes:

- `Completed`: NoValidation or validator acceptance, four exact PostValidation copies, encoded-BAL
  null fallback, optional `InsertDeferred` after publication, and the processed tuple return;
- `Rejected`: validator false after validation, proposal observation retained, disposal before
  `InvalidBlockException`, with no publication or return;
- `Escaped`: unsupported boundary or generic validator/cleanup/PostValidation/storage escape;
  only the known event prefix is retained and no final state is asserted.

Admission separates eight semantic source trees from four pinned compiler-support trees.
`Verify-Publication.ps1` runs the shared 604-test minimum, deterministic extraction comparisons,
warning-failing Lake and four direct Lean targets, fifteen semantic mutations (eight publication
plus seven finalization), and the full descendant
axiom audit before a final live suffix check. Its frozen inventory contains 1599 exports:
294 ProcessOne exports plus the 1305 upstream exports. The inventory SHA-256 is
`9af770169f8539bf833aa4519a07b6a52fd0bffad5d513d40546f9ba0bf72312`.
The full gate passed 604/604 tests with no failures or skips, including conformance and negative
controls for both published JSON schemas. Independent executable review accepted all final hashes;
the Release solution build had zero warnings/errors and both post-solution checks passed.
Exact artifacts and evidence logs are recorded in the package `README.md` and global manifest.

`CommitTree`, world reset, and block-tree/head effects are outside the suffix. Validator internals,
CLR/virtual dispatch, disposal implementation, receipt durability/canonicalization, BranchProcessor,
and BlockchainProcessor are not reimplemented. Block/receipt identities, artifact snapshots,
flag values and external normal-return/effect observations remain adapter inputs. The theorem
does not derive flags from a concrete `ProcessingOptions` mask or consume a proved finalization
result. Preserved array identity does not prove receipt contents. This conditional acceptance does not
complete the full block-processing claim.
