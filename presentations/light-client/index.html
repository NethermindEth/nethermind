05 / Run & boundaries

Run it. Know the boundaries.

Native CLI · .NET 10 · Mainnet by default · Sepolia and Hoodi options

Start from the repository root

dotnet run --project src/Nethermind/Nethermind.LightClient -c release -p:SaveDiskSpace=true -- --checkpoint-url https://mainnet.checkpoint.sigp.io

Example uses Sigma Prime's checkpoint service as the trust anchor. Alternatively provide --checkpoint <trusted-root>.

Scope to communicate clearly

  • pending, safe and earliest selectors are unavailable.
  • Transaction lookup is bounded. null means unknown in scope, not global absence.
  • Recent Electra-or-later checkpoints; this is light-client verification, not full-chain replay.

Remaining engineering work

  • Peer diversity, CL capability selection and wider interoperability.
  • QUIC/TLS conformance and lifecycle follow-up; native handler cursors/recovery.
  • Browser/mobile ports and BAL-based cache advancement remain future work.
